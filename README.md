# AUREN v0.5 — One Screen Update

Update these **three files in the root** of your existing GitHub repository: `index.html`, `styles.css`, and `app.js`. Do **not** upload the ZIP itself. Do not delete the other JS modules.

The orb is centered, tabs are behind Memory & settings, and chat history is folded by default. The most recent AUREN response is shown on the main screen. Browser-based voice and optional wake phrase are retained. No AI language model is connected yet.

To apply: on GitHub choose Add file > Upload files, drag the three extracted files, commit to main. If GitHub refuses replacing same-name files, use the file edit pencil or GitHub Desktop. Then verify the Pages deployment and reload the live site.

Limitations: browser speech recognition support varies; wake-word listening only works while the page is active and permission is granted. No background listening. Local memories should be backed up before major upgrades.
