AUREN v1.1 — Better "Hey Auren" recognition + v1.0 microphone fix

1. Extract this ZIP.
2. Upload app.js and voice.js (NOT the ZIP) to the root of your existing GitHub auren repository.
3. Commit changes and refresh the AUREN website once GitHub Pages publishes.

Changes: More speech-to-text name alternatives; recognizes "Hey Auren", "Hey Orin", "Hey Oren", "Hey Lauren" and similar when recognition is active; avoids common-name triggers without a greeting. Includes the microphone-off and natural-greeting improvements from v1.0.

A browser site CANNOT turn on a microphone by itself or reliably hear a wake phrase when the tab is closed, the phone is locked, or the user hasn't enabled wake mode. Click Enable "Hey Auren" once per page session and grant microphone access. Safari can suspend speech recognition.

AUREN uses browser speech recognition: exact wake-word reliability cannot be guaranteed. Validate in Safari and on your phone.
