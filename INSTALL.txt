AUREN v2.7 — Invisible, sourced conversations

No new tabs. No changes to index.html, app.js, voice.js, or weather.js.

1. Back up your existing Cloudflare Worker code.
2. In your Cloudflare dashboard, open the Worker that AUREN already uses.
3. Replace only the Worker code with cloudflare-worker.js, preserving the existing Workers AI binding named AI.
4. Deploy the Worker. Do not edit the URL saved in AUREN.
5. Ask: "What are the latest technology headlines?" and then "Tell me more about the first story."
6. Ask: "How can I improve my study routine?" (should answer without retrieving news).

The Worker fetches BBC News World/Business/Technology RSS only for current-information requests; it is not a general web search engine. It caches feeds for 15 minutes when Cloudflare cache is available. No search API key or paid search service is required.

Note: Cloudflare AI and Worker free allowances still apply. Origin header checks are not authentication; a public launch needs server-side rate limits and abuse protection. This update has not been tested on your live deployed Worker.
